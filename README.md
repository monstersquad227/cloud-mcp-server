# CLOUD-MCP-SERVER

## Tools

### get_account_balance
获取阿里云账户余额

## Start

### virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### install

```bash
pip3 install -r requirements.txt
```

### Run

```bash
python3 server.py
```

### Development

```bash
mcp dev server.py
```
